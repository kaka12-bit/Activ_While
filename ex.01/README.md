# Activ_While

📘 Validação de Número Positivo em JavaScript
📋 Descrição

Este programa em JavaScript tem como objetivo garantir que o usuário digite um número positivo. Caso o valor informado seja negativo, o sistema continuará solicitando um novo número até que uma entrada válida seja fornecida.

⚙️ Como funciona
A variável de controle começa com um valor negativo, garantindo que a verificação aconteça desde o início.
Um loop while é utilizado para verificar se o número digitado é menor que 0.
Enquanto o valor for negativo, o programa continua pedindo um novo número ao usuário.
O valor digitado é convertido para número antes de ser analisado.
Quando o usuário finalmente digita um número maior ou igual a 0, o loop é encerrado.
Em seguida, o programa exibe uma mensagem informando que um número válido foi digitado.
🧠 Conceitos utilizados
Loop while
Executa um bloco de código enquanto uma condição for verdadeira.
Validação de dados
Garante que o usuário forneça informações corretas antes de continuar o programa.
Entrada de dados pelo usuário
Coleta informações digitadas durante a execução.
Conversão de tipo
Transforma o valor digitado em um número para permitir comparações.
Saída de dados
Exibe mensagens informando o resultado ao usuário.
