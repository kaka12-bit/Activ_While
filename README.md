# 📘 Guia Completo: Loop while em JavaScript

## 📋 O que é o while?

O while é uma **estrutura de repetição** usada para executar um bloco de código várias vezes **enquanto uma condição for verdadeira**.

Ele é muito útil quando não sabemos exatamente **quantas vezes o código precisa se repetir**, mas sabemos **qual condição deve ser atendida**.

---

## ⚙️ Como funciona

* O programa verifica uma condição.
* Se a condição for **verdadeira**, o bloco de código é executado.
* Após executar, a condição é verificada novamente.
* Esse processo continua até que a condição se torne **falsa**.

---

## 🔁 Fluxo de execução

1. Verifica a condição
2. Se for verdadeira → executa o código
3. Volta e verifica novamente
4. Repete até a condição ser falsa

---

## 🧠 Conceitos importantes

### ✔ Condição lógica

A condição deve sempre resultar em verdadeiro ou falso.

---

### ✔ Controle da repetição

É essencial que algo dentro do loop mude ao longo do tempo, para que ele não fique rodando para sempre.

---

### ✔ Loop infinito ⚠️

Acontece quando a condição nunca se torna falsa, fazendo o programa travar ou rodar indefinidamente.

---

### ✔ Execução controlada

Um loop bem construído sempre possui um início, um meio (execução) e um fim definido.

---

## 📊 Quando usar while?

Use o while quando:

* Não souber quantas repetições serão necessárias
* Depender de uma condição dinâmica (como entrada do usuário)
* Precisar validar dados repetidamente

---

## 🔄 Comparação com outros loops

* while: usado quando a repetição depende de uma condição
* for: usado quando o número de repetições é conhecido
* do...while: usado quando o código precisa rodar pelo menos uma vez

---

## 💡 Exemplos de uso

* Validação de entrada de dados
* Menus interativos
* Processos que dependem de repetição até uma condição mudar
* Cálculos com múltiplos valores

---

## 🚨 Erros comuns

* Esquecer de atualizar a condição de parada
* Criar uma condição que nunca se torna falsa
* Usar operadores incorretos em comparações
* Não validar os dados recebidos

---

## 🧠 Boas práticas

* Sempre garanta que o loop terá um fim
* Use variáveis com nomes claros
* Mantenha o código organizado
* Evite lógica muito complexa dentro do loop
* Teste diferentes situações
