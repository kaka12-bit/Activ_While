# Activ_While

📘 Cálculo de Média com Validação de Entrada em JavaScript
📋 Descrição

Este programa tem como objetivo calcular a média de notas digitadas pelo usuário. Ele permite inserir várias notas e só encerra quando um valor negativo é informado.

⚙️ Como funciona
O programa inicia com variáveis para armazenar:
A soma das notas
A quantidade de notas inseridas
A nota atual digitada
Um loop é executado continuamente enquanto o valor digitado não for negativo.
A cada interação:
O usuário informa uma nota
Se a nota for válida (maior ou igual a 0), ela é adicionada à soma
A quantidade de notas é incrementada
Quando o usuário digita um número negativo:
O loop é encerrado
O programa verifica se alguma nota válida foi inserida

🧠 Conceitos utilizados
Loop while
Permite repetir a execução enquanto uma condição for verdadeira.
Estrutura condicional (if/else)
Usada para validar as entradas e decidir o fluxo do programa.
Acumuladores
Variáveis que armazenam valores ao longo da execução (como soma e quantidade).
Validação de dados
Garante que apenas valores válidos sejam considerados no cálculo.
Cálculo de média
Realizado dividindo a soma das notas pela quantidade de entradas válidas.

🚨 Possíveis melhorias
Validar se o valor digitado é realmente um número (evitar valores inválidos)
Limitar as notas entre 0 e 10
Exibir mensagens mais amigáveis ao usuário
Criar uma interface gráfica em vez de usar entrada simples
