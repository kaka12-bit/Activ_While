# Activ_While

📘 Simulação de Saques Bancários em JavaScript
📋 Descrição

Este programa simula um sistema simples de saques bancários, onde o usuário pode retirar valores de um saldo inicial até que ele seja zerado.

⚙️ Como funciona
O programa inicia com um saldo inicial definido.
Um loop while é executado enquanto o saldo for maior que zero.
A cada repetição:
O usuário informa o valor que deseja sacar.
O sistema verifica se há saldo suficiente.
Se o valor do saque for menor ou igual ao saldo:
O saque é realizado
O saldo é atualizado
Se o valor for maior que o saldo disponível:
O saque é recusado
Uma mensagem de erro é exibida
O processo se repete até que o saldo chegue a zero.
Ao final, o programa informa que a operação foi encerrada.

🧠 Conceitos utilizados
Loop while
Mantém o programa em execução enquanto houver saldo disponível.
Estrutura condicional (if/else)
Responsável por validar se o saque pode ser realizado.
Validação de dados
Garante que o usuário não saque mais do que possui.
Operações matemáticas
Subtração para atualizar o saldo após cada saque.
Interação com o usuário
Entrada e saída de dados durante a execução.
